# Huffman Coding Compression
lossless text compression using Huffman Coding (Python)

## Overview
This project builds the huffman coding to do lossless text compression.<br>
The program reads a text file, builds a huffman tree, creates binary codes, encodes the text and cann decode it back to its original form.<br>
It also provdes compression statisics and visualizes the hufffman tree using graphvis.

## Features
- Build frequency table from text
- Construct Huffman Tree automatically
- Generate Huffman Codes
- Encode text into binary
- Decode the binary back to text
- Display compression ratio, entropy and statistics
- Visualize Huffman tree as a PNG image
- Interactive menu interface.

## Installaltion
### Clone the Repository
`git clone https://github.com/yourusername/huffman-compression.git`<br>
`cd huffman-compression`

## Requirements
- Require Python 3.8+
- Rquire Graphvis

### Install Graphvis
Graphvis can be download for Python through <br>
`pip install graphviz`

Install Graphviz System Package<br>
windows 10/11 - Download from https://graphviz.org/download/ <br>
macOS - `brew install graphviz`<br>
ubuntu/Debian - `sudo apt-get install graphviz`

### Running Program
1. Place your input file in the dataset folder
2. run by python huffman.py
